# 软件材料一致性

核对项：软件全称/简称/版本；权利人及开发关系；实际源码与第三方来源；运行环境；功能、界面与操作步骤；模块/接口说明；日期和证明材料；当前受理规则与取得时间。

记录“已核实—依据—待补”，不要自动填姓名、身份证、签章或合作关系。开发完成日期、发表状态和权属必须由本人提供事实依据。

[国家版权局计算机软件著作权登记办法](https://www.ncac.gov.cn/xxfb/flfg/bmgz/202410/t20241015_869486.html)说明程序和文档鉴别材料及相关证明；具体提交形式、页数/行数和例外交存按当前官方及受理机构要求核验，本方法不内置永久固定数值。

## 修复内容

- worker 专用连接使用50ms忙等待，避免长时间同步阻塞计时器；启动检查和聊天领取/回执保存事务异步限时等待，默认最多10秒。仅重试 SQLite BUSY（结果码5及其扩展），不吞掉其他数据库错误。
- 模型请求只执行一次；等待的是事务提交，不重复请求模型。保存期间继续维护租约；短暂的流式片段保存或续期争用不立即取消调用。租约真正失效、取消、权限变化和旧结果隔离规则继续生效。
- 调度循环遇到短暂 BUSY 退回下一轮；其他异常保留执行阶段并正常失败，避免默默跳过错误。持续超过等待上限的争用仍可能导致本次回复无法保存，不承诺永不失败。
- 生产日志增加受限错误类、SQLite码与项目内代码行号。不会记录异常正文、SQL、模型输出、凭据或用户文件路径。
- 没有契约、数据库迁移、Windows安装器、公开版本或更新通道改动。原中断请求不重放，不改成成功；没有用量回执时不自动重复调用。

# 资料库原件下载与版本切换恢复

2026-10-17，`acceptcat`；`fix/library-original-download` 接续 PR51 / 60bd743，产品源码 **9d08fa30d870b0ee8cc20700000a02bb85868c52**。

## 解决的科研使用问题

老师和学生从“资料与素材库 → 来源与版本”取论文、笔记与素材时，原实现只调用 `response.blob()`，没有核对所选版本的原件大小或 SHA256。即使代理返回成功状态的登录页面、字节损坏或内容不完整，也可能被请求保存。下载中切换来源版本不改变操作身份，旧响应仍可能保存；只能等待30秒，没有主动停止或保存请求说明。

本轮仅修改桌面资料库：

- 当前应用会话读取明确版本，响应类型须匹配该版本记录。保留 Markdown、JSON 和其他合法原件类型，没有把任务附件的 TXT/PDF/PNG 白名单套到资料库。
- 读取过程中同时限制为该版本大小及既有10MiB上限；读完再次核对实际字节数、SHA256，匹配后才请求保存。连接、正文和校验沿用一个30秒截止。
- 独立下载组件提供停止与重试。版本、来源、账号、会话、路由、面板生命周期或禁用状态改变时取消旧读取，晚结果不触发保存；本次请求身份使用原始版本号、哈希和文件信息。
- 提示正在校验哪个版本、具体失败原因和“已请求保存”。复用任务材料已验证的 Blob 保存机制和文件名清理；取消系统下载后可再次请求，不冒称系统落盘成功。下载图标作为装饰隐藏，按钮辅助名称保持中文。

既有API在每次GET重新核对权限；前端校验不授予新权限。无法撤销此前已经保存到磁盘的副本，不能保证在一个已获准GET期间、尚未被客户端获知的服务端权限变化自动收回已传出的字节。

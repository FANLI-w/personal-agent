## 最小实现建议（尚未交付）

1. **对话绑定库。** 识别明确命名意图及选定链接，读取表与可见字段，建议论文分类及标题/年份/级别/摘要映射；表或范围不明确才追问。后台保存有名称的外部源引用，默认私人，原表仍在飞书维护，不搬整库 PDF。
2. **先查事实再回答。** 资料 Agent 将问题转为受限字段条件，后台校验并只读查询飞书，处理分页及完整性回执；模型只基于实际返回记录回答，带条件、读取时间及可回到原记录的来源。附件全文按需再读，不让模型凭记忆统计整库或执行外部资料中的代码/任意查询。
3. **后续复用库名。** 后台保存绑定，按服务、本人和课题组隔离，跨轮/重启仍可解析“论文库”；每次重查实时记录。字段变化、无权、过期和部分分页失败分别提示，不能把权限返回空列表当“没有论文”。同名库或多表应澄清。
4. **准确日期/等级口径。** 缺日期时只支持年份并说明，补具体发表日期后再支持严格过去12个月。先展示“库中标注”，自动核验需有目录版本和论文类型；Findings/Workshop 不套用主会等级。
5. **权限另行完成。** 需要最小用户身份的多维表格表结构/字段/记录只读能力，核对具体权限、应用发布、本人再授权及真实 API 试读。讨论不自动扩大权限，不申请写表、群消息或全企业访问；不得借本人 token 隐式给全组开放原文。共享范围与各成员飞书权限分别处理。

先限命名绑定、字段筛选和带来源回答；向量化、全量 PDF 下载、跨库同步、写回和通用文档管理后置，不扩建另一套飞书。

2026-10-18，`release/acceptcat-0.10.13` 接续 PR61 / 13eea26；产品源码 `8acfbed107b222c4c4f404068c8ecc6cbb821eff`。

## 用户入口

| 位置 | 内容 |
| --- | --- |
| 主侧栏 | 消息、通讯录、工作台、广场、我的；我的紧接广场 |
| 左上头像 | 直接进入 `/me`，不再弹出个人信息菜单 |
| 我的 | 个人资料、我的 Agent、课题组能力、模型设置、记忆与偏好、通用设置、版本与帮助 |
| 工作台主栏目 | 科研总览、任务规划、我的任务、资料与素材库 |
| 任务规划 | 研究计划、定时任务 |
| 资料与素材库 | 资料集合、本机报告 |

我的采用左侧纵向分类与独立内容区，不将所有设置平铺进同一表单。个人资料沿用实际账号/联系人：昵称、介绍、研究能力和交流偏好可版本化保存，号码和名片可复制；保存后更新当前身份显示。我的 Agent 延续技能库/绑定与资料管理，课题组能力延续既有授权读取和管理。

模型设置复用原编辑器，增加内嵌展示，其他现有弹窗调用保持兼容。通用设置复用语言与关闭窗口行为；版本页复用同一个更新状态组件，自动检查和原生更新服务不变，侧栏“我的”以圆点提示已有可下载/下载中的更新。版本详情与诊断收在折叠区域，旧日志上报操作只在明确点击后执行。本轮未执行日志上传。

研究模式没有独立底部设置按钮或头像 Popover；原 OpenIM 非科研模式入口保留兼容。移动端“更多”里的个人/设置入口统一进入“我的”，联系人申请和群邀请保持。

## 路由与权限

- `workbench?view=agents/capabilities` 转到 `/me` 对应栏目，保留目标 Agent 和其他参数。
- `workbench?view=skills` 转 `/me?view=agents&panel=skills`，保留 skill/catalog；广场安装链接直接使用新地址。
- 旧 `view=scheduled` 或 `tab=scheduled` 进入任务规划的定时任务；`view=reports` 进入资料栏目中的本机报告。
- 原 task/plan 深链接保持。点击工作台主栏目清除上个面板参数；在定时任务里点击“规划新任务”会切回研究计划再启动编辑。
- 迁移只改变入口，不新增权限、集合授权、技能执行能力或后台接口。账户 generation / 组件卸载继续隔离迟到结果。已在服务器提交的 A 资料保存仍属于 A，响应晚到不会修改 B 的昵称或草稿。

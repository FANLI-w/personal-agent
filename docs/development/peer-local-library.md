# 同组 Agent 索取本机资料（本地候选）

2026-10-23。负责人同意“同课题组、指定本机共享目录、聊天索取、在线直传、离线排队”的首版。独立分支 `feat/peer-local-library` 从 fetch 后 main/e393247 开始，保留 PR89 的同事聊天、资料与课题组功能。

## 使用方式

双方使用新 Windows 客户端并切换到同一课题组，配套后台须升级到 contract0.30/schema026。「资料 → 同事资料」选择专用共享目录，默认每次请求在原生窗口同意；明确选择自动共享后，同组成员可自动获取匹配文件。加入课题组不开放整台电脑。

页面选择同事并输入文件名关键词；个人助理聊天也支持“帮我找小王的实验记录”“向 AcceptCat 号要论文.pdf”等明确指令。重名用账号或页面选择，问句、引用和举例不自动创建请求。首版按文件名关键词匹配，不是全文或语义检索。唯一匹配在原请求设备自动接收，多份匹配由请求者选择。收到后保存本机并可打开，不自动进入云资料库或调用模型阅读正文。

状态回到请求者个人助理聊天，并保留页面请求列表。对方未运行客户端、未切换到该组、未设置目录或尚未同意时显示等待，不宣布已经找到或收到。请求7天有效，重启后待处理请求仍可查；中断的旧设备传输须重新查找，不保证断点续传。

## 原件和权限

目录配置仅留本机，按服务、账号、课题组及成员关系版本隔离；退出重加不继承旧目录自动授权。主进程从实际会话 Cookie 向固定科研服务核对当前账号、课题组和真实请求，读取前后重新核对，不把页面声明当权限。

文件标识只指向本机当前授权条目，不接受远端绝对路径。排除隐藏/凭据文件、符号链接和 Windows junction；读取前后核对文件身份、长度、修改时间与SHA256。每份1..10MiB，每次最多10个匹配，扫描最多10000项/12层/约3秒，达到上限明确提示部分结果。支持PDF、DOCX、TXT、MD、CSV、XLSX、PPTX、PNG、JPG/JPEG原件，不执行脚本或声称理解内容。

接收原件在 Windows 应用数据目录的 `peer-library`，保存来源和哈希；已下载副本不能远程收回。接收副本按服务/账号隔离，不因切换课题组删除。账号/组切换、取消、权限失败或本机停止共享会停止本客户端连接；已经发出的字节不能撤回。本机副本被更改或删除，打开时明确报错。

## 传输与成本

可靠有序 WebRTC DataChannel、16KiB分块、发送缓冲上限、90秒期限；接收端核对精确长度/SHA256后才保存。每设备至多两个活动连接。默认使用 `stun:stun.cloudflare.com:3478` 协助尝试直连，构建时 `VITE_PEER_STUN_URL` 可替换，空字符串只使用可直接发现的地址。首版无TURN文件中继或云端兜底，不保证校园网、防火墙或运营商NAT下必能直连；失败显示原因并允许重试。[STUN参考](https://developers.cloudflare.com/realtime/sfu/get-started/connection-patterns/)、[直连/中继参考](https://tailscale.com/docs/reference/connection-types)。

后台只保存请求、获准文件的名称/长度/修改时间/哈希、设备租期及有界SDP协商，不接收原件或本机目录。每人30个活动请求、24小时100个新请求，设备租期45秒，正常轮询4秒、错误退避30秒；过期协商清除。文件字节不经过模型，索取不要求双方配置模型Key。

## 契约、迁移与部署

契约0.30.0增加7个PEER1接口：设备续租、请求列表/创建/详情/状态变更、协商读取/提交。续租和协商提交为实时会话操作，不写普通业务回执缓存；创建/变更有幂等键，重放仍核对权限。`agentChatMessage.peerFileRequest` 是可选字段，只允许本人个人助理，不向外部Agent、群聊或其他人的Agent开放本机读取。

026只新增 `peer_library_devices`、`peer_library_requests`、`peer_library_signals` 三表及索引，001—025校验和不变。请求绑定双方成员关系版本，退出重加不复活旧请求。主进程使用兼容Electron22/Node16的窄校验，不运行ESM契约包；与服务端契约的往返另作检查。复用OpenIM聊天状态，本批为AcceptCat内部结构化协作，不宣称对外A2A兼容。

用户随后单独授权“后台可以升级”，已于2026-10-23配对部署contract0.30/schema026、镜像2677f693；一致备份、独立恢复、副本/正式迁移保全及服务健康检查通过，[部署记录](../deployment/peer-library-20261023.md)。PR91随后按负责人明确指令以merge commit 90b7687合入main，客户端0.10.35仍仅本机候选；026产生新写入后，不直接换025旧镜像或回灌旧快照。部署检查没有替代真实双机直连与用户体验验证。

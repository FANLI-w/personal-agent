# 聊天图片与文字右键操作

2026-10-26，从已同步的main/c3f7d0f新建fix/chat-image-context-actions。负责人提供的微信截图作为操作参考，仅加入本产品能实际完成的操作。

图片气泡、放大预览及待发送图片共用ChatImage：复制图片、另存为…、Windows本机提取文字；已发送消息保留引用回复。预览工具栏也提供复制与另存为。预览的portal事件不再触发消息文字菜单，不再复制“[图片]”。文字消息提供“复制消息文字”；选区的两个端点均在右键消息内时改为“复制选中文字”，在打开菜单时保存选区快照，避免菜单取得焦点后选区消失。文件和语音占位词也不作为文字复制。

复制读取原图后解码为PNG像素，通过受限Electron桥写入系统图片剪贴板。网页环境支持时使用ClipboardItem，不可用则明确报错。另存为保留原图字节与PNG/JPEG/GIF/WebP/BMP格式；桌面使用系统文件对话框及覆盖确认，仅写用户确认的路径，取消不写入也不提示成功。格式根据实际文件头判定，原图缺失或过期会报错，不用缩略图代替。GIF复制/识字使用解码帧，另存仍保留原文件。

远程原图沿用firstPartyFile的来源、无凭据/不跟随重定向、30秒和10MiB/实际长度限制；本机草稿直接使用已选File，不上传。复制/识字限制解码尺寸至30百万像素/单边40000，转换PNG同样限10MiB。IPC再次检查当前应用窗口、字节、格式及尺寸；保存对话框返回后再次核对窗口身份。切换会话/账号后的在途读取不复制或展示旧结果，OCR按既有接口取消。已经由用户明确确认的文件保存按本机对话框处理，不声称具有后台资料撤权回收能力。纯格式JS工具及类型声明在electron/utils，renderer共用同一实现；避免两个TS工程引用未生成声明的问题，主进程构建也包含该模块。

“提取文字”沿用Windows本机OCR，结果在可选择文本框中展示，可复制识别文字；不会自动发送聊天、请求Agent、创建任务或修改资料。原有获准的“识别并回复”保持独立操作。本批没有角色、契约、数据库或后台代码变化，无需后台部署。

自动检查和安装包实际状态见current-state与project-log。自动测试使用合成图片/模拟原生桥，不代表真实系统剪贴板、保存窗口或安装后视觉体验已验收；这些按负责人要求由本人检查。

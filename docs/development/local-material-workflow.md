# 本地文件为主、资料轻量共享：文件与归档

2026-10-29，基于 main/7f8775f，在独立工作副本的 `feat/local-material-workflow` 实现。客户端版本仍为 0.10.70，本批不是新公开版本。原桌面开发目录未改动。

## 使用流程

1. 从「任务」打开任务工作页，选择本地工作文件夹；已有素材可以直接放在该文件夹里，不必先上传资料。也可新建空白工作区，再用「添加本地素材」选择文件。
2. DSH 在这个目录里按需读取素材、执行工具、生成成果。「文件与归档」显示文件、打开所在目录、预览支持的文本；任务执行区也能直接添加本地素材或进入该页。
3. 需要团队材料时，在「共享资料」选择集合、文件和版本，取到当前工作目录。保存来源、版本和 SHA256，已有记录且磁盘内容相同的材料会复用；本地已修改的副本不会被当作相同内容复用。
4. 工作完成后刷新文件列表，勾选成果，选择自己可写的资料集合，核对可见范围并确认归档。只上传选中文件。成功回执可以打开资料页里的对应集合和文件。
5. 任务提交、发起人验收沿用既有流程。归档成功不自动提交或验收任务；成果仍可继续在本地修改。

独立 DSH 页面增加进入任务的入口，官方 DSH 界面及插件机制保持。以上关联以任务工作区为单位，不会自动认领任意独立 DSH 会话或扫描整台电脑。

## 文件、资料与记忆的职责

- 本地工作目录是执行和修改的主要位置。外部文件通过原生选择器导入副本；目录内文件可直接登记，不复制自身。导入不上传资料服务，也不自动把文件正文塞进提示词。
- 资料保存主动共享或归档的原件和来源版本。取用的是明确版本的本地副本，不是双向同步目录；云端更新不会覆盖正在编辑的本地文件。
- 规则、记忆、关联索引继续使用上一批机制。材料清单提供定位线索，不能替代实际读取文件，也不会把原件转成长期记忆。
- DSH 按需读取后，内容可能随模型请求交给已有账号模型服务。“未上传资料库”不表示模型执行永远离线。

不新增向量库、全盘索引、知识库服务、自动同步或新的模型密钥机制。复用现有资料列表、版本读取和原件导入接口；Cookie/CSRF、账号隔离和资料权限保持。contract 0.37.0/schema 030 不变，无数据库迁移或新增后台接口，现有后台无需为本批重新部署。

## 恢复与权限

归档前在本机保存待发送的文件快照、幂等键和进度。断网或服务端已接收但响应丢失时，重试使用原文件内容与原请求，不读取后来修改的文件。逐文件保存成功回执，多文件中途失败不会重复上传已确认部分。

只有明确的 `VERSION_CONFLICT` 拒绝允许刷新集合版本、经用户再次确认后继续；不确定结果不能用新键盲目重发。每次重试和写入都重新检查当前账号、任务权限、目标集合归属及已确认的共享范围。集合权限被撤回或范围改变后停止；本版尚无待核对批次的放弃/更换目标入口，需先恢复原授权和范围再核对原请求。

文件访问限于当前账号绑定的任务目录。原生文件选择器、路径穿越/链接校验和账号切换防护在主进程执行；渲染页不能提交任意绝对路径让主进程打开或上传。运行中禁止导入与归档，避免读写竞争。已有工具权限和任务设备占用规则不变。

## 当前边界

| 项目 | 本批范围 |
| --- | --- |
| 添加本地素材 | 一次最多 20 份，单份 50 MiB，一批 200 MiB，最多 100 条登记记录；拒绝空文件和符号链接 |
| 工作目录文件列表 | 最多 100 份、深度 3 层；不是完整文件管理器 |
| 归档 | 一批最多 5 份，单份 10 MiB，沿用现有服务限制 |
| 归档目标 | 当前账号拥有且可用的普通集合；飞书外部集合不作为原件导入目标 |
| Office 成果 | PPTX、DOCX、XLSX 保存原件，不声称已提取正文或支持应用内预览 |
| 任务提交 | 科研任务附件仍只支持既有 TXT/PDF/PNG；其他成果可归档并在提交说明中引用资料。个人任务仍为文字提交 |
| 后续编辑 | 本地修改不自动更新归档；再次归档创建新的资料文件，未增加自动版本合并 |
| 本机恢复记录 | 待核对快照保存在账号隔离的本机任务状态目录；本批无自动清理历史归档日志功能 |

下一次优先用真实项目文件验证完整工作过程，再按实际需求处理大文件和成果版本更新，不以本批为理由新建完整知识库。

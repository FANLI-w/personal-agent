# 统一科研同伴的身份、档案与私人偏好

2026-10-25，北京时间。负责人要求所有助手都像可长期合作的同事，前端能够调整角色和说话方式。此前任务规划没有联系人身份，资料页已有实际资料助手；本批让规划复用本人“研究方案助手”联系人，普通聊天、规划和资料页共用同一“助手设置”入口，打开既有角色档案及私人记忆编辑器。

## 身份与交互

- 规划优先复用已记录的本人研究方案助手，包括用户修改过的名称、人设和偏好；没有时在首次发送或打开设置时创建。资料助手同样可直接从资料页设置，在普通私聊中也能修改。模板不会覆盖用户档案。
- 规划和普通聊天读取同一位助手的档案、获准私人/会话记忆和个人记忆。明确的“以后和我聊天，……”指令沿原确定性聊天服务保存偏好并显示真实回执；不额外调用模型，不把普通抱怨、引用或问题持久保存。
- 工作台继续保存原方案版本、本机规划线程、明确日期、原话重试和创建确认；联系人日常聊天与工作台规划线程没有合并成一个跨设备聊天历史。助手关联沿原模板本机记录复用，未新增跨设备内置角色映射。
- 展开布局和绿色收起按钮沿PR102保持。修改长名称后标题可截断，设置入口继续可用。

## 后台边界

contract从0.30.0增量到 **0.31.0**，planRequest仅新增可选`colleague:{contactId,conversationId}`，不默认补空字段，保留旧请求幂等形状和旧任务执行路径。后台只接受本人站内专用助手及本人拥有、该助手已加入的直接会话；不接受他人助手、外部服务或不匹配会话。

后台自己读取档案与获准记忆，接受时绑定版本摘要，调度、心跳和回写重新核对。改人设、撤回记忆、切换外部服务或失去权限后，旧结果不能改方案，实际用量仍保留；历史方案仍可查看。人设和偏好不能改变任务确认、预算、工具能力或资料权限。

schema026保持，无数据库迁移。新引用及摘要保存在既有execution_jobs请求JSON中，不重复保存密钥。旧后台不接受新规划绑定；新客户端明确提示需升级，保留消息/旧方案和任务，不静默切回另一套人设。配套部署与main合并、安装包和公开Release分别处理，以current-state为准。

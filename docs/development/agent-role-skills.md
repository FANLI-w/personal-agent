## 内容和加载

[agents/roles](../../agents/roles/README.md) 是十类默认角色及共同交流规则的唯一内容来源。每类有 meta.json、persona.md、work.md、SKILL.md，manifest注册及选择默认类型。七位科研助手、个人助理、通用自建助手与公开证据审阅角色均已独立设计场景、判断、对话示例、工作方法和边界。新默认专门助手注册后自动进入添加列表；不再在TypeScript中维护第二套默认人格。

research-skills构建生成浏览器/API共用的roles与role-catalog子入口，原文同时复制到dist/roles。主方法加载器仍只读agents/skills，不把角色重复列成科研方法。构建会拒绝未注册目录、缺少章节、断开的入口引用和超过默认预算的模板；桌面守卫逐文件核对源与包内角色，CI触发包含agents/roles。

普通聊天、个人助理协调、资料/文件/显式Skill聊天、绑定同伴的研究规划使用同一共同规则与当前档案。无绑定的旧规划也读取canonical研究方案角色；公开证据执行读取固定审阅角色，保留严格结构、真实引用和人工审阅。生成Agent的操作仍只根据当前明确创建要求生成四个公开字段，后续以同一角色文件约定解释，不把创建器当普通聊天人设。

## 现有和私人角色

既有数据库继续保存名称、简介、capabilityDescription、personality；后两项对应work.md与persona.md，不在服务器公共目录写每位用户的私人档案，无数据库迁移。27份历史模板精确匹配数据独立保留；仅四字段全部相同的默认档案在查看/模型输入中投影为新版角色，保留原名称和存储记录。改过任何字段的档案整体保留，空字段采用对应类型默认值。稳定联系人、会话、任务、材料、外部连接和主人不变化。

角色catalog摘要进入既有上下文fingerprint；人设/偏好或角色版本变动后，旧模型结果不能回写，实际用量继续记录。私人交流纠正沿既有明确指令、private_agent记忆、历史修订和撤回，不从抱怨、引用、他人或模型内容推断持久偏好。

设置页显示实际生效的persona/work/组合SKILL文本，可编辑Markdown、分别保存文件或导出带meta和manifest的完整JSON角色包。导入兼容旧版四字段JSON；新角色包校验严格文件清单、长度、版本和组合正文一致性，转换后使用原importAgentProfile，仅创建/复用导入者自己的专门助手。包不包含账号/联系人身份、聊天、记忆、Key、外部连接或工具；来源为公开档案，导出不会隐含读取私人记忆。外部服务人设由远端维护，设置页明确本站档案不会自动发送远端。

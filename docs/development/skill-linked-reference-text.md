## 实际问题

原生导入只把SKILL.md和 `references/` 下的部分文字送入Skill包；`assets/`、`templates/`、`docs/`中的方法或文字模板虽作为本机原件完整保存，却无法在聊天的“加载技能参考文件”中选择。固定 K-Dense peer-review / 529b9f73 / Skill2.2 的9份模板中，8份有明确包内路径引用，旧导入仍仅6份可选参考。用户能看到“保留25个原件”，却不能把这些模板交给当前文字流程。

## 修改与边界

`clients/openim/electron/utils/skillImport.ts` 从已识别的说明/参考文字出发，读取普通Markdown链接、链接定义及反引号中的本地文件路径，沿已提供的文字依赖继续收集。仅限所选技能目录内已存在的 `.md/.txt/.json/.yaml/.yml/.csv/.tsv`；不会去网络下载、读取目录外文件或加载脚本。代码块示例、远程/绝对路径和逃逸路径不参与跟随；适用祖先许可仍为本机原件，不进入模型参考。图片、PDF、未提及素材仍只在本机保存。

所有新增参考保留完整UTF-8原文，继续受单文件400KB、文字总900KB、300份文字、完整原包8,000项/100MiB等原有限额约束；新增文字另校验API已有的单项120,000字符限制。超过限制、损坏编码或无效内容报错，不能静默截断。循环/重复链接去重。未提供的链接不会自动补齐，也不因此授予工具权限；复杂HTML/非文字依赖与执行步骤仍需独立适配。

`SkillLibrary`安装/更新预览逐份展示拟保存到私人账号的参考路径、字符数和原文；明确未列出的原件只保存在本机、调用时仅发送用户选择的参考。原文用React纯文字显示，不执行HTML或模板代码。预览确认前不创建服务器Skill；取消不落本机原件。安装弹窗限制内容滚动高度，修复展开模板后标题/关闭控制被挤出窗口，确认按钮保持可达。

既有私人安装不自动改变摘要、版本、参考或授权；用户重新导入并确认保存新版本后才获得新增可选文字。现有API本就允许安全的包内参考路径，**无需升级服务、迁移数据库或重新发布公共目录**。原始来源、许可、SKILL.md正文和所有原件字节均保持，变化的是新导入版本的文字引用列表与packageDigest。

# Skill素材加入资料库的范围与恢复

日期：2026-10-18（北京时间）。`acceptcat-2`，分支 `release/acceptcat-0.10.10` 接续PR58 / da6ec83；产品和安装包源码 **24858567a318ab4302f53eead42713e1405dea1f**。

## 实际问题与修改

旧素材上传在本机原件读取期间仍可更换目标集合；界面范围说明和提交闭包中的目标可能不同。原上传还绕过普通文件导入的确认、未知结果恢复与范围变化保护。原件清单读取失败时，错误下方仍显示“此修订尚无本机原件”，把失败与缺失混在一起。

`SkillMaterials.tsx` 现在先选择自己的可用集合，读取期间锁定目标及关闭入口，使用ref阻止同tick重复操作；原件准备完成只打开既有 `ResearchFileImport`，没有此时上传。随后用户在相同文件导入表单核对并确认，沿用首次请求快照/幂等key、已确认来源与刷新分流、未知结果锁定重试、版本冲突重读/范围变化阻断。`ResearchFileImport.tsx` 仅扩展可选的预备File/标签/备注，既有本地文件选择不变。

预备文件保留原始字节、文件名和类型；原路径、技能修订与SHA256预填备注，不能在该表单替换文件造成错误来源标注。选中其他素材需关闭后重新选择；标题/作者等仍可明确编辑。素材预览和另存成功/失败均在当前账号、会话、面板、Skill修订及bundle范围内提交结果；范围变更清空旧选择和准备结果，旧操作不会解锁新操作。清单读取/失败/无原件/非桌面端各有对应状态。

## 六、坑清单（都踩过）

1. **打包体积突然多 80MB**：rcedit 失败重试会留 `win-unpacked/RCX*.tmp` 被打进 NSIS。删 tmp + 用 electron-builder 绝对路径重封装即可（3 分钟）。
2. **`extraResources` 的相对路径**：构建的 projectDir 是 `.electron-runtime`，所以要写 `../tools` 而不是 `tools`，否则文件静默不进包。
3. **新增迁移**：`schema_migrations` 计数断言（15 个 spec）与"模拟旧 schema 降级"脚本（10 个 spec）都要同步；`deploy/openim/tests/production.test.mjs` 的 `max(version)` 也要改。
4. **契约升版要配 `supports(N)` 门禁**：否则旧后台会露出死页签。
5. **DSH 不会在启动时对齐 package.json 与 lock**：缺 bundle 会被静默跳过（stderr 一行），"改 spec + 删 lock" 是假成功。
6. **koffi 原生模块**：主进程模块不要经 `windowManage` 间接引入 `clipboardFiles`，否则 esbuild 打包 guard 会报 `.node` 无 loader。
7. **Windows CI 偶发超时**：表现为每次挂不同用例，先看是不是 5s 默认超时（#166 修这个）。

# 智能体与真人通讯录

负责人要求按智能体和真人分成两个页面，并参考右键菜单管理联系人。本批从最新main/d25781d新开feat/contact-directory-pages，普通merge尚待审阅的PR113/e0e911b作为删除能力依赖；没有合并主仓库main，保留双方提交与已部署contract0.33/schema027。

## 页面和操作

- 通讯录有“智能体”“联系人”两个页面，以服务返回的identity.kind分类，不从名称、头像或性格文字猜身份。每页独立显示我的/课题组范围，查找和添加也只显示相应类别；原好友申请、群邀请、群组入口保留。
- 单击条目在右侧看资料，右键或Shift+F10打开发消息、查看资料、设为/取消星标和可用的删除操作。发消息、删除和编辑沿用服务端allowedActions与原有版本/确认/幂等逻辑，未添加的课题组成员不能凭右键绕过关系。系统个人助理没有删除菜单。
- 真人及别人拥有的Agent显示“删除联系人”，本人自建专门Agent显示“删除 Agent”。删除确认在离开页面或换账号时关闭，迟到请求不会刷新另一账号。
- 星标仅为当前服务+账号的本机偏好，存稳定ID，不保存角色正文或凭据；列表当前页星标优先，换账号立即隔离，另开窗口的本机存储变更同步。不是聊天置顶，不暗称跨设备同步；存储失败不显示虚假的保存成功。
- 服务已有混合分页，客户端依次跳过没有当前类别的页，直到找到结果或确实到末页。搜索在服务端执行并沿用到每页，不只搜索已加载的50项；取消/超时或游标循环显示错误，不把失败写作暂无联系人。
- 共享名片链接先验证当前账号可读的实际身份，再跳到相应页面。切账号和切分类会隔离列表/页游标与操作；原名片来源校验保持。

## 介绍与角色信息

所有Agent资料直接显示介绍、能力描述、性格与偏好，角色文件留在可展开项，仍可导出或按本人权限编辑。任务/资料助手头部改为“助手资料”，共用同一名片。没有修改用户的角色文字、私人记忆、实际工具权限或默认科研方法。

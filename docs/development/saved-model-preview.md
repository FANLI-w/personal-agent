## 结果与接口

已保存Key用独立只读字段展示脱敏串，没有展开完整旧Key的按钮；“更换”打开新的空密码输入框，可取消更换。只改名称/型号时不提交apiKey；新Key写入成功后清空输入并重新读对应版本的预览。遮罩文字、空白和非法字符在发送前拦截；移除仍需明确勾选并保存，旧预览随后消失。字段和help说明区分读取中、已保存、待更换/移除和预览不可用。

原后台只返回hasApiKey；给原配置响应增加字段会破坏旧客户端严格Schema。因此契约兼容补丁 **0.25.1** 独立新增 `GET /api/v1/me/model-configurations/{id}/key-preview`，原配置/保存/默认选择接口响应不变，无数据库迁移。

- 仅会话本人可读自己的配置；跨账号/不存在返回404，匿名401，响应no-store。
- 使用现有绑定本人/配置ID/服务商的加密记录解密并即时裁剪，不另存明文或预览，不调用模型供应商。
- Key长度16及以上返回首尾各4字符，8–15返回各2字符，中间统一8个遮罩字符。响应只含configurationId、version、hasApiKey和apiKeyPreview；完整Key/密文不会进入该响应、业务回执、联系人或模型上下文。
- 无Key返回null；解密失败返回安全503，不影响普通模型元数据读取。前端核对ID/版本/账号，迟到或错版本预览不显示。
- 旧服务404或预览503时仍保留已有配置及“已保存”，明确预览暂不可用，不能虚构Key首尾。首尾显示需要本接口实际部署，仅安装客户端不能完成后台升级。

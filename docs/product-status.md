0.10.12 的交付记录：Windows x64 NSIS，**87,403,174字节**；SHA256 `990c217477b6747d49c5ae8da32bade0437df7ce1febc01f6dc01275aa900892`。工作台取消并列的“我的技能”，收进“我的 Agent”；助手配置内统一查看和管理技能、资料，技能库负责复用方法的安装、更新与授权。广场仍直接发现 GitHub 能力。素材可靠导入和原名片等改进继续包含。准确检查与限制见[0.10.12交付记录](deployment/acceptcat-0.10.12.md)，不代表已公开上传。

## 目前能做什么

| 方向 | 当前范围 | 仍需继续完成的部分 |
| --- | --- | --- |
| 聊天与个人助理 | 人与 Agent 联系人、流式文字、连续输入、获准偏好管理、文件阅读范围、图片识字与正文整理 | 真实科研材料下的长期使用与模型质量评价 |
| 科研团队工作台 | 可编辑计划、明确分工与依赖、邀请承接、阻碍、阶段交付、修改与验收 | 更丰富的学科流程与持续课题试用 |
| 资料与方法 | 有来源/版本的资料、授权绑定、本人 Zotero 元数据选入、私人 Skill 预览/安装/文字调用、按次选择参考 | Zotero 全文/批注/团队库、完整向量检索与通用工具执行 |
| 科研广场 | 在线目录8项来源/5个仓库；每日北京时间零点同步 GitHub 事实与待审阅发现 | 候选经过科研适配与质量验证后才能开放相应使用入口 |
| 定时任务 | 一次/每天/每周提醒及自己的文字 Agent 定时运行，运行记录可查 | 依赖持续在线的后台，不能在桌面关闭后访问本机文件夹 |

广场已收录选题/项目风险、可证伪假设、证据自查和稿件等文字流程；PaperQA、Research Toolkit 及上游高级 Zotero 工具仍标明适配条件。**文字说明可调用，不代表联网检索、绘图、统计或脚本自动执行已接通。** 当前材料的授权范围不会因为安装或公开能力而扩大。

## 源码与服务分别在哪里

最新产品功能和0.10.12打包源码在[release/acceptcat-0.10.12](https://github.com/luoyan96/personal-agent/tree/release/acceptcat-0.10.12)，固定打包源码 `da1858e`。Agent/技能管理层级、广场与工作台分工、素材导入及名片/卡片/排序/下载已进入本地试用包；[交付记录](deployment/acceptcat-0.10.12.md)区分实际打包、前端模拟通信验证与生产待办。超长Skill正文边界仍待后台配套，新增三项目录仍待运营发布；不能仅凭本包断言这些已在线。

**默认分支应用代码仍是较早的0.3.0基线；更新首页文档不会自动合并全部功能分支、发布安装包或升级后台。** 开发最新产品功能时按上述集成分支和其贡献指南准备环境，不能从首页预览反推 `main` 已包含所有新功能。

线上 API/worker 目前为 `47c42ac`，contract0.25/chat1.12/schema022；社区目录由运营者单独发布。2026-10-16凌晨确认目录8项/5仓库/20个待审阅候选，GitHub同步成功。目录刷新无需新桌面包；已安装的私人 Skill 若要使用新参考或版本，仍须本人明确更新。

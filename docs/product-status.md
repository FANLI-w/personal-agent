## 目前能做什么

| 方向 | 当前范围 | 仍需继续完成的部分 |
| --- | --- | --- |
| 聊天与个人助理 | 人与 Agent 联系人、流式文字、连续输入、获准偏好管理、文件阅读范围、图片识字与正文整理 | 真实科研材料下的长期使用与模型质量评价 |
| 科研团队工作台 | 可编辑计划、明确分工与依赖、邀请承接、阻碍、阶段交付、修改与验收 | 更丰富的学科流程与持续课题试用 |
| 资料与方法 | 有来源/版本的资料、授权绑定、本人 Zotero 元数据选入、私人 Skill 预览/安装/文字调用、按次选择参考 | Zotero 全文/批注/团队库、完整向量检索与通用工具执行 |
| 科研广场 | 目录运营PR66已报告11项来源/7个仓库；每日北京时间零点同步 GitHub 事实与待审阅发现 | 候选经过科研适配与质量验证后才能开放相应使用入口 |
| 定时任务 | 一次/每天/每周提醒及自己的文字 Agent 定时运行，运行记录可查 | 依赖持续在线的后台，不能在桌面关闭后访问本机文件夹 |

广场已收录选题/项目风险、可证伪假设、证据自查和稿件等文字流程；PaperQA、Research Toolkit 及上游高级 Zotero 工具仍标明适配条件。**文字说明可调用，不代表联网检索、绘图、统计或脚本自动执行已接通。** 当前材料的授权范围不会因为安装或公开能力而扩大。

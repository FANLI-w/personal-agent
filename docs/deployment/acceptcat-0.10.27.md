## 使用方式与范围

在课题组资料底部资料 Agent 发送“这是我的论文库＋飞书多维表格链接”。读取用户可见的数据表与字段；多表时先选表，保存命名的外部资料集合。默认且仅限本人私人范围，原表在飞书维护，不复制全部记录/PDF。再次进入可按保存的库名查询，无须每次粘贴链接。

支持显式年度、连续年份、CCF 单个等级、标题/摘要/会议关键词；“那去年呢”“对比这几篇”等追问保留已解释的条件。每次查询重读字段和实际可读记录，回执记录时间、条件、读入量、匹配量、完整性及原记录链接，再沿既有本人 Agent 私聊文件阅读与 DSH 回答。没有新增模型厂商、默认配置或独立模型规划调用；这是受限查询语言与现有模型回答的组合，不能称为任意条件的通用数据库 Agent。

库中只有年份时，“最近一年”先澄清，不能伪造过去12个月的精度。有明确发表日期列时才执行滚动日期筛选。CCF 等级依据库中标注，不独立认证发表事实；严格排除 Findings/Workshop/Short 标签，不把主会等级直接套给这些记录。未读取附件全文。

单次最多100张表、200个字段、20页/2000条记录，展示最多50条，交给模型的回执另有75,000字符上限并报告实际提供数量。到扫描上限明确部分结果；中间页失败、游标循环、字段身份/类型变化、授权撤销或集合版本变化均停止。零条可读记录不等于全库为空；高级权限限制和读取期间表变化均提示。

绑定按本人、课题组、应用、外部源去重，回执丢失复用原Key；查询回执先保存再发送，对话提交丢回执复用原字节/Key，不再次查询或生成重复消息。外部源配置加密，禁止将私人飞书库改成共享集合或混入普通上传文件。不会隐式向课题组成员转授本人的飞书权限。

首次多维表格授权由资料 Agent 的连接入口明确请求，显示只读范围；未绑定资料库的顶部原单篇文档入口和旧空 connect 请求仍使用原三项权限。现场补修后，本人已有可用私人库时重连会保留多维表格只读scope。不能将 Edge 已登录当成 AcceptCat 已获 API 访问权。

# Input

合成任务：“比较三个已获准本地模型在同一固定测试集上的结果，整理可供组会讨论的报告。”提供目标与产出，不提供真实成员分工、实验结果、文献或授权执行工具。

# Expected behavior

- 默认给出一项“比较模型并整理组会报告”任务；准备评测、比较结果和写报告都是任务内的步骤，不因三个模型或多个阶段分别创建任务。只有用户明确要求分别创建时才拆成不超过10个独立工作单元，使用真实依赖。
- 使用现有Plan字段与`dependencies`引用，步骤ID唯一且全部引用有效，无循环；方法建议放入已有说明，不凭Skill文中的通用名称新增未定义接口字段。
- 分工与依赖分别处理。没有指定真人时不编造成员ID或声称对方接受；“待认领”仅说明分工待认领，不说明前置任务已完成或被阻塞。
- 已能表达目标就给待确认任务，不因缺论文、日期或成员而先走完整咨询流程；仅在必要时问一个简单问题。不虚构结果、执行记录、验收或自动创建正式任务，正式创建仍依赖用户明确确认及原有权限检查。

# Structural boundary fixtures

`a → b → a`、`a → a`、引用不存在的步骤和重复步骤ID：显示可恢复提示，不递归崩溃或伪造关系。有效100步旧计划仍可按契约展示，不把新Skill的建议上限当成旧数据迁移。

# Executed versus pending

实际定向检查验证Skill原文注入、预算/最新请求保持、原Node规划检查及上述图结构边界。此文件只声明模型行为评价场景；真实模型拆解质量、界面与安装后体验由负责人另行检查，未标为已验收。
